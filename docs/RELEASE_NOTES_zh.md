# v0.3.1 发布说明

- 在 GitHub Release 提供包含匹配模型、数据、特征与 tokenizer 的完整 wheel 和中文说明。
- 通过 `hisca` 自动初始化独立 CPU 环境并打开浏览器，保留首页、预测、热图和候选排序。
- 同步本地最新模型源码，保留已验证的部署权重及其推理设置。
- 删除 Python 注释与文档字符串，保留普通字符串、交互文字和独立 LICENSE；检查去注释前后代码的 AST 语义一致性。
- 从当前仓库版本清理旧 Notebook 启动入口、重复启动脚本和依赖本机绝对路径的旧实验脚本。
- 保留当前训练入口、模型、特征构建脚本及可选高阶超边代码；旧代码可以通过 Git 历史找回。

完整安装包的权重为 `hisca_demo.pt`。较新的 `hisca_mh.pt` 未作为本次默认权重发布，
因为其训练脚本开关与当前模型实现存在差异，不能仅凭文件时间和张量形状判断推理语义匹配。
